# Редизайн moloko-posad.ru

Статический сайт в стиле order.oberweis.com: кремовые фоны, крупные сжатые заголовки, скруглённые карточки, кнопки-«таблетки», тёмная секция и цветной подвал. Цвет бренда — зелёный «Фёдоровских».

## Структура

- `site/` — готовый сайт (36 страниц, URL как на текущем сайте)
- `site/assets/style.css` — все стили
- `site/assets/app.js` — слайдер, корзина, поиск, фильтр каталога, форма
- `build/` — генератор страниц: контент в `data.py`, шаблоны в `layout.py` и `pages_*.py`

## Пересборка

```bash
python3 build/build.py
```

## Перед выкладкой

- Картинки сейчас грузятся с moloko-posad.ru. При переносе на сервер поменяйте `IMG` в `build/data.py` на `"/"` и пересоберите.
- Форма контактов отправляет те же поля, что и сейчас (`formid=contForm`, `name`, `email`, `message`), на `kontakty.html#contacts`.
- Поиск отправляет `search` на `rezultaty-poiska.html`; подсказки и выдача работают в браузере.
- Корзина хранится в браузере; «Оформить заказ» подставляет состав заказа в форму контактов.
- Цены, которых нет на текущем сайте, показаны как «Цену уточняйте в магазинах» — впишите их в `build/data.py`.
- Тексты политики конфиденциальности и пользовательского соглашения на текущем сайте пустые — на их страницах стоит заглушка.
